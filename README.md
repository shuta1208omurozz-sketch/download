# FloatSaver v0.7-alpha

BraveのURL取得（許可制）と、貼り付けたURLから動画を直接見つけられないときの検出方法を改善しました。

## フローティングでの操作
1. Braveで動画ページを開く。
2. FloatSaverの「↓」→「Braveで開いているURLを取得」。初回のみ「設定 → ユーザー補助」で「FloatSaver：BraveのURL取得」を有効にする。許可後はBraveの動画ページに戻って再度取得する。
3. URLが入ったら「動画を調べる」→画質・保存形式を選んで保存。
4. 「動画形式を判別できません」となるページは、同じパネルの「内蔵ブラウザで再生・検出」から開き、本編を再生。埋め込みプレイヤーが候補にある場合はプレイヤーを開いて再検出する。

BraveのURLはユーザー補助からアドレス欄の情報を取得できるときのみ読み取ります。端末・Braveのバージョンによっては取得不可です。URLは3分間だけメモリに保持し、閲覧履歴には保存しません。ユーザー補助の許可は任意です。許可しない場合は共有・貼り付けを利用できます。

yt-dlpの解析エンジンが古いと疑われるエラー時のみ、安定版への更新を試みて1回再試行します。全サイトに対応できるわけではありません。DRM、認証・署名付きURL、動画URLを秘匿するサイトでは保存できない場合があります。広告と本編は自動確定しません。

「フローティングを終了（↓も消す）」は従来どおり小窓にあります。更新APKはGitHub ActionsのBuild FloatSaver APKからダウンロードしてください。
