# FloatSaver v0.8-alpha

Braveのフローティングボタンと、動画・GIFの検出／ダウンロードを改善したAndroid用アプリの開発版です。

## 使い方

**Braveから素早く調べる**
1. Braveで動画を開き、FloatSaverの「↓」をタップします。
2. 「BraveのURLを取得して調べる」を押します（初回のみAndroidのユーザー補助設定で許可が必要）。取得できたら自動解析します。
3. 画質・推定容量・保存形式を選び、「ダウンロードを開始」を押します。

**動画が見つからないとき**
1. 同じフローティング画面上部の「ページを再生して動画を探す」を押します。
2. 内蔵ブラウザで動画本編を再生し、必要に応じて「再生後に検出」。
3. 本編と思われる候補をタップして画質選択へ。広告候補は別に表示・警告し、自動保存しません。

**GIFは元のGIF形式で保存**。動画は可能な形式でMP4/WebM/MKV等を選択できます。ただし動画ファイルへの直リンクは原形式のまま保存します。保存場所は `Download/FloatSaver`。

## v0.8の変更

- 動画ファイル直リンク（MP4/WebM/MKV/MOV等）はHEADでメディアと確認できれば、一般サイトの解析エンジンに頼らず直接保存できます。HTMLやJSONのエラーページを動画として保存しない対策を追加。
- HLS/DASH形式の拡張子・通信情報を手掛かりにした動画候補の検出を拡張。HTMLの埋め込みプレイヤー、data-video-src / data-hls-src等、VideoObjectのcontentUrlを候補として表示。
- DRMやログイン制限を回避する機能ではありません。すべてのURL・サイトで保存できるわけではありません。
- 明らかな動画抽出エラーでのみ、解析エンジン更新・1回再試行（更新頻度制限あり）。ダウンロード途中の失敗ファイルを残さない対策。
- フローティングはURL取得と解析をワンタップに統合。解析に失敗したら内蔵ブラウザへすぐ移れるよう上部にボタンを表示。
- Android APKビルド・テストはGitHub Actionsで行います。ビルド成功は実サイトでのダウンロード成功を保証するものではありません。

広告判定はあくまで推定で、広告と本編を確実に区別できません。Braveの内部通信は取得できず、BraveのアドレスバーURL取得はユーザー補助で明示的に有効にしたときのみ機能します。
